# Мир мотоциклов — Система оформления заказов

## 1. Название приложения
**Мир мотоциклов** — приложение для просмотра каталога и оформления заказов мотоциклов.

## 2. Используемые технологии
- **Язык:** Python 3.14
- **GUI:** PySide6
- **СУБД:** PostgreSQL
- **Драйвер БД:** psycopg2-binary

## 3. Назначение и основные функции
Приложение автоматизирует работу магазина. Реализованы следующие функции:
- Каталог товаров с изображениями, ценами, скидками и остатками.
- Автоматический расчёт скидки 25% для моделей без заказов в прошлом месяце.
- Цветовая индикация остатков (голубой — нет в наличии, розовый — мало).
- Авторизация по логину (без пароля), разграничение прав по ролям (Гость, Клиент, Менеджер, Администратор).
- Поиск, фильтрация и сортировка в реальном времени.
- Просмотр списка заказов для менеджеров и администраторов.

## 4. Порядок подготовки БД и запуска
1. Установите PostgreSQL, создайте базу данных `mir_moto`.
2. Выполните SQL-скрипт `src/db/database.sql` в pgAdmin для создания таблиц и импорта данных.
3. Активируйте виртуальное окружение: `source venv/bin/activate`.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите приложение из корневой папки: `python -m src.app.main`.
